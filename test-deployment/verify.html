Historical declaration verification

Read-only, without wallet connection, signing or transactions. This page locally processes voluntarily disclosed real identity/bank identifiers; creation pages remain synthetic-only. Enter all thirteen exact original fields to compare the current-format SHA-256 digest with the acceptance snapshot stored at the time of acceptance, including older acceptances. An older snapshot made by another method will show a mismatch, not an automatic fallback or a claimed match. An unsalted public hash can be guessed; enter sensitive details only if you understand that risk. Original fields remain in this browser tab; only public wallet and contract addresses and optional transaction hash are sent to the selected RPC. The on-chain snapshot is bytes32 and does not record the hashing scheme; a mismatch cannot identify which method created it.

Exact serialization

Thirteen-field current format: SHA-256 over domain-separated, ordered UTF-8 field names and exact values, each prefixed by uint32 big-endian byte lengths. Domain: cryptopassport:SDT:identity:v2\0, then uint32 big-endian field count 13. See the exported report for the ordered field list and reproducibility instructions. No trimming, case conversion, Unicode normalization or silent date, amount or time correction. Birth date must be a real DD.MM.YYYY calendar date.

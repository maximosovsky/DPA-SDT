Support and requests

For site support, privacy requests, security concerns or complaints, use a GitHub issue in the project repository (the project repository is private, so only people with repository access can open its issues), or contact the operator through LinkedIn if its messaging option is available to you.

Profiles and limitations

The operator's GitHub profile and repositories identify the account; ORCID is an identifier, not a messaging channel.

What not to send

GitHub issues are public if the repository allows them; availability and visibility of an issue route may change.

Do not post or send private keys, seed phrases, passwords, identity documents, bank documents or sensitive personal information. For a privacy request, describe the request and the affected page or public transaction without sharing sensitive material.

If neither route is available to you, the site does not currently provide a separate verified private support address.

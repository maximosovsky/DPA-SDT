# Fixed-price DPA unit sale — experimental local/testnet

`DPAShareSale(unitsAddress)` escrows exact ERC-1155 `UNIT_ID=1` units from a seller with `createOffer(namedBuyer, amount, totalPriceWei)`. Offer IDs start at 1; status `None=0, Open=1, Sold=2, Cancelled=3`. Price is for the **entire** offered lot, not per unit. There are no partial fills, open-market matching, expiry or fees. While open, only the named buyer can call payable `buy(id)` with exactly the fixed native ETH price. One transaction marks the offer sold, credits the seller, and transfers the units to the buyer; if any step fails the whole transaction reverts. The seller alone may `cancel(id)` while open and recover the unsold units. `withdraw()` pays accrued seller credit via a pull payment, resets credit before the external call, and reverts/reinstates it if the payout fails. All custody transitions use `nonReentrant`, validate the exact expected ERC-1155 receipt; direct/batch deposits are rejected. Contract constructor captures the unit address and creation chain ID. It does not validate canonical units/formation; the UI does that before signing.

Use `/shares.html` first to claim fractional units following completed synthetic DPA formation. Navigate to `/sale.html`, connect a test wallet on **local loopback 31337** or **Base Sepolia 84532**, and enter the exact formation and units addresses. Verify canonical formation/SDT, units and sale runtime plus immutable links before enabling actions. Deploy a separate sale escrow from the page if needed. Seller approves `setApprovalForAll(sale,true)` (broad allowance over all current/future units), specifies one buyer, amount of *available* units and positive total test-ETH price, and creates offer. Enter its ID and inspect on-chain terms. Switch to named buyer wallet, reconnect/reverify, inspect, then buy with exact test ETH. Seller reconnects and withdraws the credited proceeds. Seller can instead cancel an **open** unsold offer. The UI rechecks account, chain and canonical code before writes, simulates transaction, and reads receipt/state afterward; controls reset on wallet/address change. Revoke the broad ERC-1155 approval directly through a wallet/contract tool after use if no further offers are desired.

Run `npx hardhat test test/DPAShareSale.test.ts`, `node --experimental-strip-types --test test/share-sale-ui.test.ts`, `npm run build`, then `node scripts/sale-local-runner.mjs` for a loopback EVM and Playwright browser flow using two local mnemonic-derived wallets. **Do not use those publicly known mnemonic keys on a public chain.** This is no legal assignment, securities determination, exchange, price oracle, real-money product, or guaranteed value; token ownership alone establishes none of those. No public network transaction or hosted release is implied by the local tests.

# Experimental specification

Scope: Self-Declared Token (SDT) and minimal SDT-only Decentralized Partnership Agreement (DPA), on an isolated local EVM and, only with explicit wallet signing and free funds, Base Sepolia (chain ID 84532). No mainnet configuration. Non-upgradeable contracts; no privileged administrator.

Identity digest: SHA256 of exact UTF-8 bytes `full_name|DD.MM.YYYY|passport_number|bank_transaction_id`. Client rejects empty fields, `|`, unpaired UTF-16 surrogates, invalid calendar dates. No trimming, Unicode normalization, salt, wallet address, or bank proof. Synthetic data only; interface additionally requires `Synthetic ` name, `TEST-` passport, `SYNTH-` bank ID. This client restriction does not constrain arbitrary direct contract callers.

SDT: self-mint a nonzero 32-byte digest, unrestricted duplication, ERC-721 ownership, ERC-5192 `locked` indicator and Locked-by-construction update hook. Holder alone burns. Immutable original issuer/hash/issuance block persists, with burned flag. Ownership no longer exists after burn. Directly changing the digest is impossible. Wallet control can still be sold/transferred. Public digest is not anonymous and is vulnerable to dictionary attacks. No token URI or personal inputs on chain.

DPA: constructor freezes one trusted SDT address and exact SHA256 UTF-8 hash of a synthetic agreement text. Text is in source/UI and must be retained externally, not on chain. One acceptance per wallet per DPA. EIP-712 domain `Experimental DPA`, version `1`, executing chain ID and actual DPA contract. `Accept(address wallet,bytes32 agreementHash,address sdt,uint256 tokenId,bytes32 identityHash,uint256 nonce)` signed by holder EOA; anyone may relay. Contract reads holder and identity hash at execution and uses its immutable own agreement hash and trusted SDT, consumes nonce, stores wallet-indexed snapshot (token ID, hash, agreement hash, acceptance block, count), emits event. Separate DPA versions/deployments can reuse the same SDT. No ERC-1271 contract wallets, alternative authenticated mode, amendment, revocation, signatures archive, shares enforcement, identity verification, bank oracle, payment, adjudication, or bridge. The submitted EIP-712 signature appears in transaction calldata, while historical recovered signer and snapshot are on chain.

Finality: local receipts show inclusion in simulated blocks only. The current synthetic Base Sepolia NFT package pilot has receipts in `evidence/base-sepolia/nft-package-pilot/`; no L1 finality or explorer-verification claim is made.
